Catalogue data

manami-project / anime-offline-database

  • Licence: Open Database License (ODbL) 1.0. Source: github.com/manami-project/anime-offline-database

  • The Anikki catalogue is a derivative database and is offered under the ODbL. The public catalogue file will be provided here with the first store version.
  • Attribution: "Contains data from manami-project / anime-offline-database, licensed under ODbL 1.0."

AniDB

Cover images (linked, never self-hosted)

Anikki does not copy or host these images. The app loads them from the source when a cover is shown; this can be switched off in the app ("Load covers from the web"). Images remain the property of their owners. Rights holders can report an image by e-mail and it will be removed: kontakt@anikki.app

Identifiers

MyAnimeList

  • Anikki uses MyAnimeList ids only as keys to match titles. Anikki does not fetch any data from MyAnimeList directly and shows no images or ratings from there. Some title values come from the openly licensed databases named above, which may in turn rest on MyAnimeList entries. A MyAnimeList export file is read only if you import it yourself, on the device, without upload.
  • MyAnimeList is a trademark of its owner. Anikki is not affiliated.
