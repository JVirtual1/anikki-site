Anikki ist eine kostenlose Anime-Liste für Android. Es gibt kein Konto, keinen eigenen Server und keine Analyse-Werkzeuge.

2. Was auf deinem Gerät gespeichert wird

Alles, was du in Anikki einträgst, bleibt auf deinem Telefon:

  • deine Liste (Titel, Status, Bewertung, Fortschritt, Notizen, Daten, die du selbst setzt);
  • deine Einstellungen (Sprache, Schalter, Benachrichtigungen) und, falls du ihn einträgst, dein Name für die Begrüßung;
  • der Katalog (die Titeldaten, die mit der App mitgeliefert werden);
  • die Termine für Benachrichtigungen über neue Folgen (lokal erzeugt; es gibt keinen Push-Server).

Wenn du eine MyAnimeList-Exportdatei importierst, wird sie auf deinem Telefon gelesen und nicht hochgeladen. Dazu legt Android eine Kopie der Datei im Zwischenspeicher (Cache) der App ab. Sie bleibt auf deinem Telefon; Android kann den Zwischenspeicher leeren, und beim Deinstallieren von Anikki wird er entfernt.

Mit „Daten sichern“ (Profil > Einstellungen) schreibt Anikki eine Sicherungsdatei an einen Ort, den du selbst auswählst. Sie verlässt dein Telefon nur, wenn du sie selbst weitergibst oder in einem Cloud-Ordner speicherst.

Hast du die Gerätesicherung von Android aktiviert, kann Android die Daten von Anikki in der Sicherung deines Google-Kontos ablegen. Das steuern Android und Google, nicht Anikki; abschalten kannst du es in den Android-Einstellungen.

Deinstallierst du Anikki, werden diese Daten von deinem Telefon entfernt.

3. Was Anikki aus dem Netz lädt und wohin Daten gehen

Anikki sendet keine deiner Listendaten, Bewertungen oder Notizen an uns oder an Dritte.

Anikki stellt Verbindungen zu folgenden Diensten her:

4. Was Anikki nicht tut

  • keine Werbung;
  • keine Analyse-, Tracking- oder Werbe-SDKs;
  • kein Konto und keine Anmeldung;
  • keine Übertragung deiner Liste, deiner Bewertungen oder deiner MyAnimeList-Datei;
  • keine Push-Benachrichtigungen von einem Server (alle Benachrichtigungen werden auf dem Gerät erzeugt).

Sollte sich das in einer späteren Version ändern (zum Beispiel Werbung oder kostenpflichtige Funktionen), wird diese Erklärung vorher angepasst, und die Änderung wird in der App angekündigt.
